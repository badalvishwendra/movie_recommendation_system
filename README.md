# CineMatch AI

A responsive, AI-inspired movie recommendation interface. Choose a film and receive a curated set of similar movies based on style, tone, and genre.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deploy

- **GitHub Pages:** Enable Pages for the `main` branch, using the repository root as the source.
- **Vercel:** Import the repository as a static site. No build command is required; the output directory is `.`.
